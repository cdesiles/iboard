# Checkbox

A 14pt checkbox with a `line-strong` edge and a 12pt label, used for Auto (auto-reload from disk and save on leave).

- Checked fill is `accent` with an `on-accent` tick, so state reads at a glance even at this size.
- The whole label is the hit target (24pt tall).
- Give the tooltip the full meaning: "Reload when files change on disk".
