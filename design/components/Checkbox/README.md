# Checkbox

A 14pt checkbox with a `line-strong` edge and a 12pt label, used in Settings › General, for instance for Auto (reload from disk and save as you type).

- Checked fill is `accent` with an `on-accent` tick, so state reads at a glance even at this size.
- The whole label is the hit target (24pt tall).
- Say what it does under it, in a help line that follows its state.
