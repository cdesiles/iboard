# Column

One column per folder: `todo/`, `ready/`, `doing/`, `done/`. Equal widths between `column-min` and `column-max`, `space-5` apart.

- **Header**, 24pt: a 14pt status icon (`status-icon`), the title in title case in `ui-strong` `ink` ("Todo"), and the count right-aligned in `meta` (Inter) `ink-muted`. No rule under it. The count is the only issue count on the board; the status bar does not repeat a total.
- **Status icon**, in the status colour, a different shape per column so colour is never the only signal (`theme::status_icon`):
  - Todo: an empty circle, r 5.25, 1.5pt stroke (`status-todo`).
  - Ready: a dotted circle, twelve 1.75pt dots on r 5.25 (`status-ready`).
  - Doing: the empty circle with its right half filled inside, r 3.25 (`status-doing`).
  - Done: a filled circle r 6 with a 1.5pt check in `surface` (`status-done`).
- The Column card shows the title case header next to the uppercase `ui-label` one for comparison; title case is the norm.
- Hovering a header swaps its count for its column actions, right-aligned ghost icon buttons that fade in over `motion-hover`: Todo's `+`, Ready's `play`, Doing's agents or Done's `release` and `archive`. At rest only the count shows. Hovering an action shows its short title in a `surface-hover` pill, `ui-strong` 12pt `ink`, left of the whole row of icons: the icons never move and none is covered. Its tooltip keeps the full description and key.
- A column holding picked cards (see IssueCard) shows a `close` icon button right after its title, "Clear selection"; `esc` does the same.
- Todo's `+` column action opens the NewIssueModal (same as `⌘N`). Ready, Doing and Done have none: new issues always start in Todo.
- Ready's `play` column action, "Enable AI auto-build", turns AI auto-build on: it hands its issues (after the filter) to the AI build agent (Settings › AI build), one at a time from top to bottom: each moves to the next column, then the agent implements it from the project folder, following the project's own instructions. It stays in Ready's header with no issue too, waiting for one to arrive, dropped there or written by another process, and building it. While it runs, `play` becomes a `stop` square that stays in Ready's header even at rest; stopping leaves the issue where it is. A failing agent stops the run and names the issue in the error strip. Without a build agent set up, `play` opens Settings › AI build.
- Doing's header action shows on hover: the `users` icon, whose pill and tooltip say "2 agents". A click opens a popover under it, "Build agents", with the stepper: `−`, "2 agents", `+` and a line saying each takes the next Ready issue and none stops the build. The popover stays open while it is used and closes on a click outside or `esc`. From 0 to 16, 1 by default. The count is the user's: Settings › AI build shows the same one, saved in `[build] agents`, so the next launch opens with it. Each agent takes the next Ready issue of the run, so 2 agents build 2 issues at once; adding one mid-run starts it at once, removing one lets the agents at work finish. 0 stops the AI build; `play` then starts it again with one agent. A card's `stop` stops only its agent.
- Done's controls end with `release`, then `archive` on its right. `archive` moves every issue it lists (after the filter) to `.archive/`.
- `release` opens a release flow on the issues it lists: the next tag from `[stats] release_tags`, a note they fill (written to `CHANGELOG.md` at the project root), then a commit and annotated tag, then a push. Each step waits: **Confirm** runs it, **Skip** leaves it out, **Cancel** stops the flow; what earlier steps did stands. It stays in Done with no issue too: a commit since the last release tag is enough to release, and with neither it is disabled. A workspace board merges repositories, so it offers no release.
- Cards stack with `space-3` gaps. Todo and Ready follow the file names (Ready's `001-` prefix is its priority); Doing and Done put the most recently edited first.
- Dragging a card to a position in Todo or Ready renumbers that column's files (`001-`, `002-`, ...) so the file order matches the board. A 2pt `accent` line shows where the card will land.
- **Empty column**: a dashed 1pt `line` well, no fill, `radius-md` corners like a card, 12pt padding, saying "No issues in doing/" centred in 12pt `ink-faint`. It doubles as the drop target: while a card is over it, solid `accent` on `accent-soft`. While AI auto-build is on, Ready's well adds a second line under it: "Bring a ticket here to process it with AI auto-build"; otherwise the one line stands. In egui, paint the dashes along a rounded path (`theme::RADIUS_MD`); dashing a plain rect gives square corners.
- Done cards keep full contrast. Do not grey out finished work; the column already says it is done.
