Export the board as markdown checklists

Drafted

Pasting the board into a PR description means retyping every title. Export one markdown file per column instead, each issue as a checklist item.

Context

The board is the source of truth, but sharing it today is manual. A plain export keeps iboard file-first and needs no new UI beyond one menu item.

Acceptance criteria writing

  • ☐ One file per column, named after the column
  • ☐ Each issue is - [ ] Title; Done issues are checked
