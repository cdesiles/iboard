AI assist to refine an issue

Challenge an issue before anyone picks it up, so a human or an AI can implement it without guessing. The Challenger reads the issue, pushes back on what is vague or too big, and offers numbered resolutions you can pick with one key.

Context

Most issues start as a title and a sentence. By the time someone takes one from Ready, the missing decisions surface as questions in the middle of the work, when they are the most expensive to answer.

Acceptance criteria

  • Refine opens the RefinePanel on any Todo issue
  • Each round offers two to four numbered choices and a free note
  • The refined draft lands in the Editor, unsaved

Notes

Keep the agent one-shot for now. The file is the truth: the agent never writes it, Apply to draft does.
