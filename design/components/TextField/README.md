# TextField

The filter input: 24pt tall, `line-strong` border, `ink` text, `ink-faint` placeholder.

- Placeholder says what it filters: "Filter tickets". It matches title, summary and file name.
- Show the `⌘F` hint inside the right edge while empty; hide it once there is text.
- `esc` clears the filter; the board shows "No tickets match "review"" per empty column.
- Width 220pt in the header; do not let it grow.
